# Lecture 6: Regression analysis

Instructor: Peter Kempthorne. Case Studies 1 (CAPM regressions on stocks) and 2 (exchange-rate regimes).

## The ideas
- Linear model y = X beta + e. Ordinary least squares: beta_hat = (X'X)^{-1} X'y, the projection of y onto the columns of X.
- Gauss-Markov: with uncorrelated, equal-variance errors, OLS is the best linear unbiased estimator.
- Normal errors give exact distributions: t-statistics for each coefficient, F-tests for groups, R^2 for fit. Maximum likelihood gives the same beta.
- Diagnostics: residual plots, leverage and influence (the hat matrix, Problem Set 3), heteroscedasticity, autocorrelated errors. Generalized M-estimation for heavy tails.

## Formulas
- se(beta_hat) = sqrt(sigma^2 diag((X'X)^{-1})), t = beta_hat / se.
- Newey-West (HAC) errors correct for autocorrelated errors, needed when y's overlap (5-day returns sampled daily).

## Watch out
- Test many signals and some will "work" by luck. With N tests, demand |t| above the Bonferroni value z(1 - 0.05/2N): 3.62 for 168 tests.
- A high t in-sample that vanishes out of sample was overfitting.
