# Lecture 2: Linear algebra

Instructor: Choongbum Lee.

## The ideas
- A matrix is a data set (rows: stocks, columns: days) and also a linear map. Eigenvectors are the directions the map only stretches: A v = lambda v.
- Symmetric matrices (every covariance and correlation matrix) have real eigenvalues and an orthonormal set of eigenvectors: A = U D U'. This is why principal components exist and are uncorrelated.
- The largest eigenvalue of a symmetric matrix is the most it can stretch a unit vector.
- Singular value decomposition: every m x n matrix is U Sigma V'. The singular values are the square roots of the eigenvalues of A'A. Keeping the largest few gives the best low-rank approximation of a data set.
- Perron-Frobenius: a matrix with positive entries has a largest eigenvalue that is positive with a positive eigenvector. (It returns in Lecture 25's recovery theorem.)

## Formulas
- Covariance of returns: S = (1/(n-1)) X'X for de-meaned returns X.
- Portfolio variance: w' S w. PCA: S = sum lambda_k u_k u_k'.

## In the skill

## Watch out
- With N assets and T days, a random matrix with no structure still has eigenvalues up to (1 + sqrt(N/T))^2. Only eigenvalues above that edge are real factors; factors.py prints the edge.
